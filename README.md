# 💰 Controle Financeiro

Projeto de controle financeiro simples, desenvolvido para praticar 
TypeScript, lógica de programação e manipulação do DOM.

## 🚀 Funcionalidades

- Adicionar transações de entrada e saída
- Listar transações em tabela
- Editar transações
- Remover transações
- Cálculo automático de:
  - Total de entradas
  - Total de saídas
  - Saldo atual
- Validação de formulário

## 🛠️ Tecnologias utilizadas

- HTML
- CSS
- TypeScript
- JavaScript
- Font Awesome

## 📌 Como usar

1. Clone o repositório
2. Abra o arquivo `index.html` no navegador
3. Adicione, edite ou remova transações

## 🎯 Objetivo do projeto

Este projeto foi criado com foco em aprendizado, para reforçar:
- Lógica de programação
- Tipagem com TypeScript
- Organização de código
- Boas práticas em projetos front-end
